## 실무에서 맡고 있는 시스템

### 협력사 포털 (PPS)

약 500개 협력사와 800여 개 활성 현장 엔지니어 계정이 파트너 등록, 계약, 교육과 문서 업무에 사용하는 B2B 포털입니다. 화면·API 개발부터 배포와 운영까지 맡고 있습니다.

- 300~400건의 첨부파일을 한 번에 내려받을 때 요청이 장시간 유지되던 흐름을 비동기 작업과 상태 조회 방식으로 변경했습니다.
- 기능별로 흩어져 있던 알림 발송 조건과 수신자 정보를 공통 정책으로 모아 운영 설정으로 제어할 수 있게 했습니다.

### 교육용 스마트기기 사업 운영 시스템 (TSMS)

11만여 대의 교육용 단말 정보와 보급, 설치, A/S, 점검 업무를 관리하는 시스템입니다. 현업 요구사항 협의부터 신규 기능 개발, 사용자 검수와 배포까지 담당합니다.

- 브라우저에 노출되던 외부 API 키를 서버 프록시로 옮기고 25개 화면의 호출 경로를 공통화했습니다.
- 사이트별 URL 규칙을 설정으로 관리하고 게시글 ID 추출, 중복 확인과 의심 게시물 이력 저장을 한 흐름으로 구성했습니다.
